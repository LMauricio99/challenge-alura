# Encriptador de texto

Proyecto de aprendizaje desarrollado para el desafío del programa **Oracle Next Education (ONE), Oracle + Alura LATAM**.

La aplicación transforma texto ingresado por el usuario y permite recuperar su versión original mediante las reglas de sustitución del desafío. Su propósito es practicar fundamentos de programación y desarrollo frontend; no debe utilizarse para proteger información sensible.

## Tecnologías

- HTML
- CSS
- JavaScript

## Estructura

```text
index.html     Página principal
css/           Hojas de estilo
js/main.js     Lógica JavaScript
source/        Recursos del proyecto
```

## Ejecutar localmente

```bash
git clone https://github.com/LMauricio99/challenge-alura.git
cd challenge-alura
```

Abre `index.html` en tu navegador. También puedes utilizar un servidor local para desarrollo.

## Objetivos de aprendizaje

- Practicar la transformación de cadenas de texto con JavaScript.
- Conectar la entrada del usuario con una interfaz HTML.
- Organizar la presentación mediante CSS.

## Mejoras previstas

- Documentar las reglas exactas de sustitución y las entradas admitidas.
- Añadir ejemplos de uso y una captura de la aplicación.
- Verificar el uso desde dispositivos móviles y con teclado.
- Publicar una demo después de comprobar su funcionamiento.
