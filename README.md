# Encriptador de texto

Este fue uno de mis ejercicios del programa ONE de Oracle y Alura LATAM. Lo hice con HTML, CSS y JavaScript para practicar cómo recibir un texto, transformarlo y mostrar el resultado en la página.

Permite encriptar y desencriptar mensajes con las reglas de sustitución del desafío. Es un ejercicio de programación, no una herramienta para proteger datos.

## Cómo abrirlo

```bash
git clone https://github.com/LMauricio99/challenge-alura.git
cd challenge-alura
```

Abre `index.html` en el navegador o usa Live Server. El código JavaScript está en `js/main.js`, los estilos en `css/` y los recursos en `source/`.
